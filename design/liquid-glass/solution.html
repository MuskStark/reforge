1目标与范围

围绕自动诊断出的三类节点，按解决顺序逐一消除：线下节点 3 → 0、系统不互通节点 3 → 0、无法实现移动端节点 4 → 0。 最终 12 个节点全部线上办理、全部支持移动端，跨系统衔接无断点。

2分优先级方案明细
第一优先线下节点转线上3 个节点 方案完成
现状

发票粘贴与签字、部门预算审核、纸质凭证归档 3 个节点线下办理

原因

财务要求核对发票原件；预算岗用纸质台账；档案室只收纸质凭证

方案

发票影像上传 + 电子签名替代粘贴签字；预算校验并入费控；凭证转电子会计档案，纸质原件按规定留存

效果

线下节点 3 → 0，单据不再跨部门传递

负责人 陈昊产出 节点线上化方案 ×3
第二优先系统不互通3 个节点 · 另含 ① 新增的 1 处衔接 需 CTO 评估接口可行性
现状

行程预订、借款申请、付款结果回写 3 个节点与上一步系统不互通，靠邮件 + Excel 搬运

原因

商旅平台只提供对账文件、没有实时接口；财务系统与费控分属两家厂商

方案

三处逐一对接：OA → 商旅平台（单点登录 + 审批结果推送）、商旅平台 → 费控（消费数据回写）、财务系统 → 费控（付款状态回写）；① 新增的预算审核 → 财务复核衔接一并打通

效果

系统不互通节点 3 → 0，人工搬运 0 处

负责人 陈昊产出 对接方案 ×4
第三优先线上节点移动化7 个节点（原 4 个 + ① 新增 3 个） 需 CTO 评估移动端可行性
现状

行程预订、借款申请、报销单填写、财务复核 4 个线上节点无法实现移动端

原因

商旅平台、财务系统没有移动端；费控的移动端组件未采购

方案

费控采购移动端组件（覆盖借款申请、报销单填写及 ① 新增的 3 个节点）；行程预订、财务复核以移动待办页承接

效果

无法实现移动端节点 4 → 0，移动可办 5/9 → 12/12
