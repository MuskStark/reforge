# ReForge 访问速度治理方案(v1 · 2026-11-22)

> 范围:flow.summer.fan(Cloudflare Tunnel)大陆访问速度,从根因到长期架构的完整治理。
> 原则:**安全模型不动**(源站零暴露、内网零入站),速度分层治理、每层实测验收。
> 所有数字均来自 2026-11-22 本网络实测,非估算。

---

## 一、现状诊断(实测)

### 1.1 链路事实

```
大陆用户 ──▶ CF 免费版 anycast ──▶ LAX 洛杉矶边缘 ──▶ CF 骨干 ──▶ Tunnel 回国内连接器 ──▶ 10.5.20.90:3000
            (DNS 无优选)          TCP 250~290ms
```

### 1.2 关键指标基线

| 指标 | 基线值 | 说明 |
|---|---|---|
| 命中机房 | **LAX**(美西) | 免费版对大陆无就近调度 |
| TCP 连接 | 250~290ms | 纯物理绕行 |
| 完整请求中位数 | **2.59s** | 5 次采样取中位 |
| 劣化尾部 | 7~13s | 国际链路丢包,TLS 握手重传爆炸 |
| 内网直连对照 | **7ms** | 慢 370~1850 倍,瓶颈 100% 在广域链路 |

### 1.3 网络环境盘点

| 资源 | 状态 |
|---|---|
| 服务器 | 10.5.20.90,内网,无公网 IPv4,无 IPv6 |
| Cloudflare 连接器 | ×2(Windows ×1、Linux ×1),均在局域网 |
| 专属 AdGuard Home | **10.5.20.14**(已确认,API 在线);全网 DNS 经网关 10.5.20.1 转发至此 |
| 本网络到全部 5955 个 CF IP | 最优 157ms(FRA)/176ms(HKG),**无 <150ms**——办公宽带国际出口质量一般 |
| 优选 IP 实测收益 | 经 172.67.197.142(HKG):中位数 **1.63s(↓37%)** |

### 1.4 根因结论

慢 = **绕行(300ms 级 RTT)× 丢包(TLS 尾部 10s 级)**,二者都源于"用户→CF 海外边缘"这一段。免费套餐内能改善绕行(优选 IP)与抗丢包(QUIC),但改不了物理距离;要进 <100ms 档必须把国内入口前移(frp 中继)。

## 三、治理措施全景

### M1 · CF 面板传输优化(0 元 · 10 分钟 · 你操作或给我 API Token)

| 开关 | 位置 | 值 |
|---|---|---|
| HTTP/3 (QUIC) | Speed→Optimization | ✅(抗丢包核心杠杆) |
| 0-RTT | Speed→Optimization | ✅(复连省 1 RTT) |
| Brotli / Early Hints | Speed→Optimization | ✅ |
| TLS 1.3 | SSL/TLS→Edge | ✅(最低版本保持 1.2) |

### M2 · 边缘缓存(0 元 · 5 分钟 · 与 M1 同面板)

Cache Rule:URI Path `/_next/static/*` → Eligible for cache + Edge TTL 1 month。
Next 静态资源带内容哈希,命中边缘即不进隧道——**二次访问提速的大头**。

### M3 · DNS 优选调度(0 元 · 30 分钟 · 我实施)

1. AdGuard(10.5.20.14)加重写:`flow.summer.fan → 172.67.197.142`(HKG,176ms,已验证可服务)
2. 备选 IP:`104.26.1.215`(HKG,3.45MB/s)
3. flow 服务器部署**周日自动换优**:cfst 复测 → AdGuard API 更新重写 → 日志留档
4. 个人设备临时手段:hosts 命令(Mac/Win 各一行)

**预期合计(M1+M2+M3)**:首开中位数 2.6s → **0.7~1.0s**;页面内 API(连接复用)→ 250~350ms。

### M4 · 国内 frp 中继(¥30~100/年 · 要 <100ms 必上 · 我实施)

安全模型与 CF Tunnel 完全一致(内网主动外连、零入站、中继只见密文):

```
大陆用户 ──▶ 国内轻量 VPS(frs,30ms)──frp 隧道──▶ 10.5.20.90
海外用户 ──▶ CF Tunnel(现状不动)────────────────▶ 10.5.20.90
```

1. 买国内轻量服务器(阿里/腾讯最低配即可)
2. VPS:frps(TCP 直通,systemd,防火墙只开监听端口)
3. flow 服务器:frpc 主动外连(Docker 或 systemd)
4. DNS 分流:AdGuard 重写改为——大陆设备 → VPS 入口;海外设备(如需要)→ CF
5. 验收:大陆 API 往返 ≤100ms

**预期**:大陆首开 ≤0.3s,API 往返 30~80ms——**10~30 倍于 P0 水平**。

### M5 · 持续监控与自愈(0 元 · 我实施)

1. **拨测**:flow 服务器 cron 每 10 分钟对当前入口做 3 次采样,记录中位数到 `/var/log/flow-speed.log`
2. **阈值告警**:中位数 >2s 或连续 3 次 >1.5s 时,自动触发一次 cfst 复测换优;仍超标则在日志标记(可接通知)
3. **月度报告**:汇总 P50/P95、换优历史(脚本生成)

## 六、风险与回滚

| 措施 | 风险 | 回滚 |
|---|---|---|
| CF 开关 | 个别老设备 QUIC 兼容 | 关掉对应开关即可,秒级 |
| AdGuard 重写 | 优选 IP 失效/被墙 | 删除重写规则即恢复默认 anycast |
| 连接器协议切换 | 极端情况隧道断连 | cloudflared 改回 auto 重启,秒级 |
| frp 中继 | VPS 故障 | AdGuard 重写切回 CF 入口,双通道互备 |
